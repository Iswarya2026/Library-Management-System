# Library Management System

- Project Name: Library Management System
- Database: MySQL
- Tool: MySQL Workbench
- Language: SQL

## Project Overview
The Library Management System is a database project developed using MySQL. It helps manage student details, book information, and book issue and return records.

## Objectives
- To maintain student information.
- To store and manage book details.
- To maintain book issue and return records.
- To retrieve information using SQL queries.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables

### 1. Students
Stores student ID, name, department and email.

### 2. Books
Stores book ID, book name, author, category and quantity.

### 3. Issue Records
Stores issue ID, student ID, book ID, issue date, return date and status.
